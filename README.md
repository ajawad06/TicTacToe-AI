# 🧠 Tic Tac Toe AI

This is a **Python-based Tic Tac Toe game** that allows a human player to compete against an **AI opponent** powered by the **Minimax algorithm** and **Alpha-Beta Pruning** for optimal decision-making.

---

## 🎮 Features

- ✅ Human vs AI gameplay  
- ✅ AI uses **Minimax algorithm** for optimal moves  
- ✅ **Alpha-Beta Pruning** optimization for faster decision-making  
- ✅ Detects **wins, draws, and invalid moves**  
- ✅ Clean and simple **command-line interface (CLI)**  
- ✅ Fully modular — easy to understand, modify, and extend  

---

## How to Run

### 1️⃣ Clone this repository:

```bash
git clone https://github.com/ajawad06/TicTacToe-AI.git
cd TicTacToe-AI
```
